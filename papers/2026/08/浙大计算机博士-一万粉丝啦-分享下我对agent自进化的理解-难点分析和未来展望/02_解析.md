# 解析
## 一句话结论
该视频并非单一论文解读，而是浙大博士对"Agent 自进化”领域的系统性综述，核心观点是 Agent 进化正从单一的 Prompt 优化，转向基于 Skill 库构建、Harness（外壳）自动优化以及“任务即训练”的闭环反馈体系。

## 要解决什么问题
解决 Agent 在复杂任务中表现不稳定、无法从历史经验中持续积累能力、以及单纯依赖大模型参数更新成本过高的问题。旨在让 Agent 具备“自我迭代”能力，通过失败归因、技能内化和系统组件化，实现低成本、可迁移的持续进化。

## 核心方法（白话）
视频梳理了四条主要技术路线：
1. **Prompt 级进化**：利用文本梯度（TextGrad）或自动提示优化（APO），像反向传播一样自动修改提示词。
2. **Skill 级进化**：将成功的操作轨迹提取为分层技能库（SkillX, Trace2skill），通过聚合多用户轨迹（SkillClaw）或失败归因（SkillForge）来更新技能，甚至将通用技能内化进模型参数（美团 Skill 系列）。
3. **Harness 级进化**：不改动模型本身，而是自动优化 Agent 的“外壳”或执行框架（如 Meta-Harness, AHE），让系统结构适应任务。
4. **任务即训练**：将日常任务直接转化为反馈驱动的优化循环，实现“边做边学”。

## 和现有路线差在哪
传统路线多关注单次任务的 Prompt 微调或模型全量/微调更新。该综述强调**模块化**和**解耦**：将能力拆解为可复用的 Skill，将执行逻辑拆解为可编译的 Harness，并区分“通用能力内化”与“任务特定能力保留在提示中”（Skill0.5），比单纯的全量微调更灵活、成本更低。

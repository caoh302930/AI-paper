### 视频简介

ICLR26-Huxley-Gödel Machine: Human-Level Coding Agent Development by an Approximation of the Optimal Self-Improving Machine
https://arxiv.org/abs/2510.21614

1. 论文核心: Huxley–Gödel Machine（HGM）研究 coding agent 如何在自修改树中选择更有长期价值的分支，关注的是后代自进化潜力而不只是当前分数。
2. 问题背景: DGM、SICA 等方法主要用当前软件工程 benchmark 表现引导扩展，高分节点可能很快停滞，普通节点却可能孕育更强后代，这种错位被称为 Metaproductivity–Performance Mismatch。
3. 理论连接: Gödel Machine 通过证明预期长期效用提升来接受自修改；论文在最终 agent 才有奖励、评测可重复、预算有限且已知等假设下，证明真实 CMP oracle 足以模拟这一接受机制。
4. CMP 定义: Clade-Metaproductivity 把一个节点及其后代组成的 clade 看成一条 lineage，聚合这条分支继续演化后可能得到的最终表现；GMP 则描述整棵树的全局长期潜力。
5. 搜索算法: HGM 汇总 clade 内成功/失败评测形成 CMP 估计，为节点建立 Beta 后验，用 Thompson Sampling 在扩展和评估时处理不确定性，并随剩余预算调整探索与利用。
6. 运行方式: HGM 将生成 child 与测试已有 agent 解耦，评估细到单个 agent–task 对；失败分支可以早停，异步版本还能在多个 CPU 上并行扩展和评估。
7. 估计证据: 在 SWE-Verified-60 和 Polyglot 上，HGM 估计与经验 CMP 的加权相关为 0.778 和 0.626，明显高于 DGM、SICA 的主要对应结果。
8. 搜索结果: 最多 800 次任务评测时，HGM 在 SWE-Verified-60 达到 56.7%，用 517 个 CPU 小时；在 Polyglot 达到 30.5%，用 347 个 CPU 小时，均优于 DGM 和 SICA 的受控结果。
9. 系列定位与限制: AEVO、AHE、Continual Harness、Autogenesis 分别覆盖进化环境、可观测 harness、在线改写和资源协议，HGM 补的是 lineage 选择与预算调度；它的理论依赖强假设，benchmark 也可能过拟合，不能外推成通用自我改进或 AGI 证明。

## TL;DR and contributions
这篇论文提出了一种名为 **MemCoE** 的框架，旨在解决大语言模型（LLM）智能体在长期对话中如何有效管理记忆的问题。核心思想是模仿人类大脑的“前额叶 - 海马体”分工，将记忆管理拆解为两个阶段：先学习“如何组织记忆”（制定全局指南），再学习“具体记什么”（执行更新策略）。通过这种两阶段优化，MemCoE 在 PersonaMem、PrefEval 和 PersonaBench 三个基准测试中均显著优于现有的静态模板和强化学习基线方法。

**Main contributions:**
- 提出了受认知心理学启发的两阶段优化框架，解耦了记忆的组织原则（How）与内容选择（What）。
- 设计了 **Memory Guideline Induction (MGI)** 阶段，利用对比反馈作为“文本梯度”来优化全局记忆指南。
- 设计了 **Guideline-Aligned Memory Policy Optimization (GMPO)** 阶段，利用指南对齐的奖励信号进行多轮强化学习，训练具体的记忆演化策略。
- 在三个长上下文个性化基准上实现了 SOTA，特别是在处理噪声数据和长历史追踪方面表现稳健。

**Compared against:** Long Context, RAG, Mem0, A-Mem, LightMem, MemAgent, MEM-$\alpha$.
**On datasets:** PersonaMem (长对话偏好追踪), PrefEval (显式/隐式偏好), PersonaBench (含噪声的用户数据检索)。
**Headline improvements:** 在 PersonaMem (32K) 上达到 **57.06** (基线最高 53.58)，在 PrefEval (显式) 上达到 **81.30** (基线最高 72.30)，在 PersonaBench (0.7 噪声) 上达到 **25.09** (基线最高 24.45)。

## What matters, what doesn't

- **🎯 Core idea (read carefully):** 核心在于“先学规则，再学执行”的两阶段设计。第一阶段通过对比学习生成一个通用的自然语言“记忆指南”（Guideline），第二阶段利用这个指南作为强约束来训练具体的记忆更新策略。这是解决长程优化不稳定的关键。
- **🔧 Useful in practice:** 文本梯度（Textual Gradient）的构建方式（对比正负样本轨迹生成自然语言反馈）以及指南对齐奖励（Guideline-Aligned Reward）的设计，对于构建任何需要长期记忆的 Agent 系统都有直接参考价值。
- **📎 Nice to know:** 跨模型迁移性实验（Table 3）表明，在一个模型上优化的指南可以很好地迁移到其他模型，这暗示了记忆原则的通用性。
- **⚠️ Deprecated / superseded:** 传统的静态提示词模板（Hand-crafted templates）和仅依赖最终结果奖励的稀疏 RL 方法（如早期 MemAgent 变体）在长程稳定性上已被证明不如本方法。

## Context and prerequisites

要真正理解 MemCoE，你需要建立两个核心概念的直觉：一是**LLM 记忆管理的困境**，二是**认知心理学中的图式理论（Schema Theory）**。

首先，LLM 的上下文窗口是有限的，无法无限存储对话历史。现有的方法通常有两种极端：一种是“暴力存储”，把所有历史都塞进上下文，但这会导致噪声干扰和计算成本爆炸；另一种是“外部记忆库”，通过检索（RAG）或总结来维护记忆。然而，现有的外部记忆系统大多依赖人工设计的规则（比如“只保留用户提到的名字”），这些规则是静态的，无法适应不同用户千变万化的表达习惯，也无法从错误中自我进化。更高级的方法尝试用强化学习（RL）来让模型自己决定记什么，但 RL 在长序列任务中面临“奖励稀疏”的问题——模型要经过几十轮对话才能得到一次反馈，这导致它很难学会“现在记这个，是为了十轮后回答问题”，训练极不稳定。

其次，论文引入了认知心理学的**图式理论**作为灵感来源。人类大脑在处理记忆时，前额叶皮层（Prefrontal Cortex）负责制定策略和规则（比如“我要记住这次约会的地点和时间”），而海马体（Hippocampus）负责具体记录事件细节。前额叶提供了一个稳定的“组织框架”，海马体在这个框架下灵活地填充内容。MemCoE 正是模仿了这一机制：它不直接让模型在混乱的对话中盲目地决定记什么，而是先让模型学会一套“记忆指南”（相当于前额叶的规则），这套指南告诉模型“什么样的信息值得记”、“以什么格式记”。有了这个稳定的指南，模型在第二阶段（相当于海马体）执行具体记忆更新时，就有了明确的约束和目标，从而避免了 RL 训练中的盲目探索。

## Method

### The big picture (layman version)

想象你要训练一个私人助理记住你的喜好。以前的做法是：要么把所有聊天记录都给它看（太慢且容易乱），要么给它写死几条规则（比如“只记吃的”），或者让它自己瞎猜（强化学习，但很难教好）。MemCoE 的做法更像是在教一个聪明的学生：
第一步（MGI）：我们不急着让它记东西，而是先给它看很多“好例子”和“坏例子”。比如，一个例子是它记对了你的生日，另一个是它记错了。我们让大模型分析这两个例子的区别，生成一段自然语言的“评语”（比如：“你应该在用户提到具体日期时记录，而不是只记大概”）。我们把很多这样的评语汇总，提炼成一条通用的“记忆操作指南”。这就好比给助理发了一本《记忆操作手册》。
第二步（GMPO）：现在助理有了《手册》，我们让它真正去处理对话。每当它要更新记忆时，我们不仅看它最后回答得对不对，还要看它更新记忆的过程是否严格遵守了《手册》里的规则。如果它按手册操作且回答正确，就给予高分奖励。通过这种方式，我们训练出一个既懂规则、又能灵活执行记忆的专家。
这种方法之所以有效，是因为它把“怎么记”（规则）和“记什么”（内容）分开了。规则一旦学会，就能稳定地指导后续所有操作，解决了传统 RL 方法在长对话中容易“迷路”的问题。

### The walkthrough

我们将方法拆解为两个紧密耦合的阶段，从动机到实现逐步展开。

**阶段一：记忆指南诱导 (Memory Guideline Induction, MGI)**
*动机*：现有的记忆更新规则通常是人工硬编码的，缺乏适应性。我们希望通过数据驱动的方式，自动学习出一套最优的“记忆操作规范”。
*核心机制*：将提示词（Prompt）视为可优化的参数。
1.  **对比反馈作为文本梯度**：对于给定的对话历史 $\mathcal{H}$ 和查询 $x$，我们使用当前的指南 $\mathcal{S}^{(k)}$ 生成多条轨迹（Trajectories）。其中，回答正确的轨迹记为 $\tau^+$，回答错误或不佳的记为 $\{\tau_j^-\}$。
    我们利用一个反馈提示 $\mathcal{P}_g$，让 LLM 对比 $\tau^+$ 和 $\{\tau_j^-\}$，生成一段自然语言的反思（Reflection）。这段反思本质上就是**文本梯度**（Textual Gradient），它指出了当前指南的不足。公式表示为：
    $$g^{(k)} = \mathrm{Grad}\big(\tau^+, \{\tau_j^-\}; \mathcal{P}_g\big)$$
    这里的 $g^{(k)}$ 不是数值梯度，而是一段文字，例如：“指南过于关注时间，忽略了地点信息”。
2.  **批量梯度聚合**：单个样本的反馈可能具有偶然性。为了获得更稳健的更新方向，我们在一个批次（Batch）$\mathcal{B}$ 上聚合这些文本梯度。通过聚合提示 $\mathcal{P}_a$，将多个样本的反馈总结为一条通用的修改建议 $G^{(k)}$：
    $$G^{(k)} = \mathrm{Aggr}\big(\{g^{(k)}\}_{(\mathcal{H},x)}; \mathcal{P}_a\big)$$
3.  **指南优化**：利用 $G^{(k)}$ 对当前指南 $\mathcal{S}^{(k)}$ 进行自然语言编辑，得到更新后的指南 $\mathcal{S}^{(k+1)}$。这个过程迭代进行，直到指南收敛到一个能最大化期望奖励的状态 $\mathcal{S}^\star$。

**阶段二：指南对齐的记忆策略优化 (Guideline-Aligned Memory Policy Optimization, GMPO)**
*动机*：有了好的指南 $\mathcal{S}^\star$，我们需要训练模型在具体场景中如何执行记忆更新。传统的 RL 只给最终答案奖励，导致策略不稳定。
*核心机制*：引入过程奖励（Process Reward）。
1.  **指南对齐奖励**：除了传统的**答案奖励** $\mathcal{R}_{\text{ans}}$（回答是否正确），我们新增了一个**指南奖励** $\mathcal{R}_{\text{S}}$。这个奖励通过 LLM 评分，判断模型生成的记忆更新内容是否严格遵循了 $\mathcal{S}^\star$ 中规定的格式和原则（例如：是否包含了必要的字段，是否去除了冗余信息）。
    总奖励函数定义为：
    $$\mathcal{R}(\tau) = (1 - \lambda) \cdot \mathcal{R}_{\text{S}}(\tau; \mathcal{S}^\star) + \lambda \cdot \mathcal{R}_{\text{ans}}(\tau)$$
    其中 $\lambda$ 是平衡系数。
2.  **策略优化**：使用 **Group Relative Policy Optimization (GRPO)** 算法来优化模型参数 $\phi$。GRPO 是一种高效的 PPO 变体，它在一组轨迹（Group）内计算相对优势（Advantage），而不需要单独的 Critic 模型。
    目标函数是最大化期望奖励：
    $$\phi^\star = \arg\max_{\phi} \mathbb{E}_{(\mathcal{H},x) \sim \mathcal{D}, \tau \sim \pi_\phi} [\mathcal{R}(\tau)]$$
    通过这种方式，模型不仅学会了如何回答问题，更学会了在回答问题之前，如何按照“指南”去构建一个高质量的记忆库。

## Challenges in the field — and what this work addresses

1.  **长程优化中的奖励稀疏与不稳定**：
    *   **难点**：在长对话中，记忆更新的效果往往要等到几十轮之后才能通过最终答案体现。传统的 RL 方法（如 MemAgent）仅依赖最终结果奖励，导致信号极其稀疏，模型难以区分是“记错了”还是“检索错了”，训练容易震荡或收敛到局部最优。
    *   **本文方案**：通过 MGI 阶段生成的指南，在 GMPO 阶段引入了**指南对齐奖励**。这是一个密集的过程奖励（Dense Process Reward），它告诉模型每一步记忆更新是否“合规”。这相当于在长程任务中插入了多个中间检查点，极大地稳定了训练过程。

2.  **静态规则无法适应动态用户偏好**：
    *   **难点**：现有方法多依赖人工设计的 Prompt 模板（如“提取用户姓名”）。但不同用户的表达习惯差异巨大，静态规则无法覆盖所有情况，导致在分布外（Out-of-Domain）数据上表现不佳。
    *   **本文方案**：MGI 阶段通过对比学习自动诱导指南。这意味着记忆规则是从数据中“长”出来的，能够捕捉到数据中隐含的、人工难以总结的规律（例如“用户喜欢用隐喻表达偏好”），从而具备更强的泛化能力。

3.  **记忆库的噪声累积与遗忘**：
    *   **难点**：随着对话轮数增加，记忆库中容易混入无关信息（噪声），或者关键信息被错误覆盖（遗忘）。
    *   **本文方案**：实验表明，MemCoE 在 PersonaBench 的高噪声设置下表现最佳。这是因为指南 $\mathcal{S}^\star$ 明确定义了“什么该记，什么该忘”，使得模型在演化过程中具有更强的抗噪性，能够过滤掉干扰项。

**未解决的问题**：
*   **多目标权衡**：当前设计主要关注单一的记忆演化目标。如何在“记忆稳定性”（不遗忘）和“可塑性”（适应新偏好）之间进行显式的动态平衡，仍需进一步研究。
*   **评分器的可靠性**：第二阶段依赖 LLM 作为评分器来生成指南奖励，如果评分器本身有偏差，可能会误导策略优化。

## Experiments and results

实验在三个基准数据集上进行，涵盖了显式/隐式偏好、不同长度上下文及噪声环境。

*   **整体性能**：
    *   **PersonaMem (32K)**: MemCoE 达到 **57.06**，显著优于最强的基线 MemAgent (53.58) 和 A-Mem (48.26)。
    *   **PrefEval (显式偏好)**: MemCoE 达到 **81.30**，比 MemAgent (72.30) 高出近 9 个百分点。
    *   **PersonaBench (0.7 噪声)**: MemCoE 达到 **25.09**，在噪声极高的情况下依然保持领先，证明了其鲁棒性。

*   **消融实验 (Ablation Study)**：
    *   移除 MGI 阶段（即使用人工 Prompt）：性能大幅下降（PrefEval 显式从 81.30 降至 73.20），证明自动诱导指南至关重要。
    *   移除 GMPO 阶段（即仅使用指南不优化策略）：性能也显著下降，说明仅有规则不够，还需要策略去执行。
    *   移除对比反馈（CF）或指南奖励（GR）：性能均有小幅但一致的下降，验证了两个关键组件的有效性。

*   **跨模型迁移性**：
    *   在 Qwen2.5-7B 上优化的指南，直接用于 GPT-4o-mini 或 Gemini-2.5-flash，依然能取得比基线更好的效果，证明了指南的通用性。

*   **效率分析**：
    *   MemCoE 在保持最高精度的同时，推理时间处于中等水平，优于那些需要多次调用 LLM 进行提取和合并的复杂方法（如 A-Mem）。

## Open questions and limitations

1.  **评分器偏差 (Scorer Bias)**：第二阶段依赖 LLM 作为“裁判”来评估记忆更新是否符合指南。如果这个裁判模型本身存在偏见或幻觉，可能会导致策略学习到错误的“合规”行为。
2.  **计算开销**：虽然推理效率尚可，但训练阶段（特别是 MGI 的迭代和 GMPO 的多轮 Rollout）需要大量的 LLM 调用，成本较高。
3.  **指南的固化风险**：一旦指南 $\mathcal{S}^\star$ 在 MGI 阶段确定，它在 GMPO 阶段是固定的。如果用户偏好发生剧烈变化，固定的指南可能无法适应新的记忆模式。
4.  **多目标冲突**：当前方法主要优化单一目标（回答正确），未显式处理“记忆简洁性”与“信息完整性”之间的权衡。

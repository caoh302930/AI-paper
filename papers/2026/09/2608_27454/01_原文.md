### 视频简介

WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution
https://arxiv.org/abs/2608.27454

1. 论文核心: WikiSkill 在不可变执行轨迹和可执行 Skill 之间加入持久 Wiki，把失败模式、成功策略、历史提案和验证结果整理成下一轮可读取的知识。
2. 问题背景: 既有技能进化方法会分析轨迹并修改 Skill，但经验常分散在提案历史和评分记录里，后续更新难以系统利用旧证据。
3. 三层架构: Raw Layer 保存原始轨迹，Wiki Layer 保存可累积的模式与演化日志，Skill Layer 保存当前生效的程序性规则；Skill 可回滚，Wiki 保留。
4. 一轮循环: Inference Agent 跑训练任务，Wiki Maintainer 从成功和失败轨迹中整理模式，Skill Proposer 读取 Wiki 后提出 Skill 更新，验证门只接受验证分数严格提升的版本。
5. 关键设计: 训练执行 Agent 默认不能读 Wiki，避免它直接拿知识解题而产生信息量变低的轨迹；Wiki 主要服务于技能提案者。
6. 案例: ALFWorld 中，第 0 轮泛化提案因验证不涨被拒，第 1 轮形成“不要把物品放回原位”的具体规则，后续证据又推动技能补上防止重复操作的规则。
7. 实验证据: 论文覆盖 LiveMath、SealQA、SpreadsheetBench、OfficeQA 和 ALFWorld 五个基准，以及五个 Qwen、Gemma、Gemini 模型；WikiSkill 在五个模型平均分上都超过最强竞争方法。
8. 规模与迁移: Qwen-3.5-9B 带 WikiSkill 的平均准确率为 47.4%，超过 Qwen-3.6-27B 无 Skill 的 39.4%；其他模型演化的 Skill 有时比自进化 Skill 更有效，但模型特定的绕行技巧也会造成负迁移。
9. 系列定位: SkillOpt 更偏用评测反馈训练 Skill，Trace2Skill 更偏从轨迹提炼补丁，Agent Skill Lifecycle 检查 Skill 是否被目标模型真正消费，WikiSkill 补的是跨轮持久知识这一层。
10. 适用范围与限制: 当前实验把 Skill 全量注入 system prompt，没有覆盖大型技能库的检索组合；Wiki 还没有自动修剪，也没有评估数百步或数小时任务中的在线技能适配。
